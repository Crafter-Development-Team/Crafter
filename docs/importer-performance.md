## 修复与优化

- CTM 同类邻居剔面仅对玻璃类生效，不再把半砖/楼梯的暴露侧面误删。
- 空气方块先跳过，避免六邻居查询。
- 全部面被遮挡的方块不再输出无引用顶点/UV，减少排序、内存和 OBJ 体积。
- 面数组原地压缩，避免复制整份顶点、UV、材质数组。
- 本地 palette 每种方块只查一次全局 ID，而非逐个体素哈希。
- 材质合并复用目标查询表；LOD 路径同样复用。
- 方块状态名称在批次冻结后预计算，避免每个体素重复解析字符串。
- 缓存卸载改为每张表单次扫描，替代每区块创建线程及重复全表扫描。
- 全模型输出内部拆成较小工作组，工作结束后按固定顺序合并。
- 最终去重恢复内部并行度，不沿用已经结束的外层线程预算。
- 自动分块：批次最多 64 区块，工作内存预算 70%，线程由 CPU/内存共同限制（最高 32），而非固定 4。
- 保留新版 tint、overlay 元数据和 UV-aware 面去重；补充 MCA 长度不可超出分配扇区的校验。

CPU 峰值不代表持续满载：加载、排序、合面与文件写出仍有串行阶段。
首轮同旧源码/同 MSVC/同 4 线程对照也从 8.441 秒降至 5.594 秒，证明消除重复工作独立有效。
